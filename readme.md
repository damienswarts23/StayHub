# 🌙 About STAYHUB

STAYHUB is a modern accommodation platform designed to help travelers, students, couples, families, and solo guests discover premium places to stay with ease.

The platform focuses heavily on:
- Modern luxury-inspired UI
- Glassmorphism aesthetics
- Smooth user experience
- Beautiful accommodation discovery
- Seamless booking flow
- Responsive design
- Real-world backend integration

The goal behind STAYHUB is to create a platform that feels cinematic, modern, premium, and comfortable while still remaining functional and user-friendly.

# 🎨 Design Philosophy

STAYHUB was designed around:
- Dark cinematic interfaces
- Soft blur/glass effects
- Warm premium accent colors
- Smooth rounded layouts
- Minimal clutter
- Luxury travel aesthetics

The interface aims to create a modern premium experience rather than a traditional booking website.
